## 2026 AI·OSS 해커톤 경진대회

AI와 오픈소스를 활용해 문제를 해결하고, 프로젝트 결과물을 GitHub 공개 저장소로 공유하는 해커톤입니다.

| 항목 | 안내 |
| --- | --- |
| 현재 단계 | 개최 예정 |
| 행사 일시 | 2026.11.27.(금) ~ 11.28.(토), 무박 2일 (예정) |
| 장소 | 추후 안내 |
| 모집 기간 | 2026.11.02.(월) ~ 11.19.(목) (예정) |
| 신청 방법 | 추후 안내 |
| 대상 | 대전대학교 재학생 · 2학기 Semi-CoAct 교과목 수강생 참여 시 우대 |
| 참가 분야 | ① (비SW) AI를 활용한 융합형 문제해결 ② AI 기반 소프트웨어엔지니어링(AI-Driven SE) ③ 기타 |
| 참가신청서 | [최신 양식 내려받기](application-2026.hwpx) |
| 결과물 | 계획서·최종 결과보고서(프로토타입 시연 포함)·발표 자료를 GitHub 공개 저장소에서 확인할 수 있어야 함 |

신청서 내려받기는 접수 완료를 의미하지 않습니다. 위 일정은 운영계획(안) 기준입니다. 장소와 신청 방법은 추후 안내합니다.
